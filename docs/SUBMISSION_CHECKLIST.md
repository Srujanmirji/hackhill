# Submission checklist

## Before any round
- [ ] Check the Unstop dashboard **and** the Top-500 WhatsApp group for the live deadline
- [ ] Submit at least 6 hours early

## Prototype round
- [ ] Public GitHub repo, clean README with screenshot
- [ ] `pip install -r requirements.txt && streamlit run app/streamlit_app.py` works from a fresh clone
- [ ] Real MCX data loaded (`source == MCX`), no synthetic banner
- [ ] Hosted demo link (Streamlit Community Cloud)
- [ ] Demo video (see DEMO_SCRIPT.md), uploaded unlisted on YouTube or Drive with view access
- [ ] TinyFish first run completed (required by organisers)

## Social pitch round
- [ ] LinkedIn post tagging Eren, BuilderBase, Nexido, Web3 India — with demo video + repo link
- [ ] Instagram Reel tagging Eren.dev, BuilderBase, Nexido, Web3 India
- [ ] Links submitted via the official form

## Finale (Manali)
- [ ] Contract specs verified against MCX PDFs (`CONTRACT_SPECS.md` log filled in)
- [ ] One stretch feature done (carry panel or measured slippage)
- [ ] Laptop runs the app offline from a local parquet file
- [ ] Answers ready: "Where's the edge?", "Why not live data?", "How is this different from other teams?"
